# 현금영수증 자동 업로드

> ## 프로그램 개요

CJFreshway에서 현금영수증 내역을 Toss Payments를 통해 자동으로 업로드할 수 있도록 하는 프로그램입니다.

엑셀 파일을 선택하고 버튼만 누르면 **파일 분할 → 로그인 → 업로드**까지 모든 과정이 자동으로 진행됩니다.

진행 중 문의사항은 **010-5033-1343** 으로 연락 부탁드립니다.

---

> ## 사전 준비

실행 전 아래 두 가지가 준비되어 있는지 확인합니다.

| 항목 | 확인 방법 |
|---|---|
| Python 설치 여부 | 시작 메뉴에서 `python` 검색 후 확인 |
| Chrome 브라우저 설치 여부 | 크롬 아이콘이 바탕화면 또는 시작 메뉴에 있으면 OK |

---

> ## 처음 한 번만 하는 설정

### Step 1. 파일 받기

전달받은 zip 파일의 압축을 해제합니다.

압축 해제하면 아래 3개 파일이 나옵니다.

```
📁 압축 해제 폴더
 ├── main.py
 ├── requirements.txt
 └── 실행.bat
```

> ⚠️ 3개 파일은 반드시 **같은 폴더**에 있어야 합니다.

---

### Step 2. 실행.bat 더블클릭

`실행.bat` 파일을 더블클릭합니다.

검은 창(명령 프롬프트)이 뜨면서 필요한 프로그램들을 자동으로 설치합니다.

```
Cash Receipt Auto Upload
========================

Installing packages...

Starting program...
```

> ⏳ 처음 실행 시에만 설치 과정이 있으며, **이후부터는 바로 실행**됩니다.

---

> ## 매달 사용 방법

`실행.bat`을 더블클릭하면 아래와 같은 프로그램 창이 나타납니다.

---

### Step 1. DRM 보안 해제 확인

원본 파일에 DRM 보안이 걸려 있으면 파일을 읽을 수 없습니다.

아래 순서대로 보안을 해제한 뒤 진행해주세요.

1. DRM 프로그램이 설치된 **회사 PC**에서 원본 파일 열기
2. **파일 → 다른 이름으로 저장 → Excel 통합 문서 (*.xlsx)** 선택 후 저장
3. 저장된 파일을 이 프로그램에서 사용

> ⚠️ DRM이 걸린 파일을 그대로 사용하면 분할 단계에서 오류가 발생합니다.

---

### Step 2. 파일 선택

**원본 파일** 항목에서 **찾기** 버튼을 눌러 이번 달 현금영수증 엑셀 파일(`.xlsx`)을 선택합니다.

- 파일을 선택하면 **분할 파일 저장 폴더**가 자동으로 지정됩니다.
- 저장 폴더를 변경하고 싶을 경우 **변경** 버튼으로 원하는 폴더를 지정할 수 있습니다.

---

### Step 3. 파일 분할

**파일 분할** 버튼을 클릭합니다.

```
✅  총 N개 파일 생성됨
📁  C:\현금영수증_분할       [폴더 열기]
```

- 분할이 완료되면 저장 위치가 표시됩니다.
- 분할 파일은 **지정한 폴더**에 바로 저장됩니다.

```
📁 현금영수증_분할\
  ├── 현금영수증_분할_1.xlsx
  ├── 현금영수증_분할_2.xlsx
  └── 현금영수증_분할_3.xlsx
```

> **폴더 열기** 버튼을 누르면 분할된 파일 목록을 바로 확인할 수 있습니다.

---

### Step 4. 업로드

#### 로그인 정보 확인

아이디와 비밀번호가 올바른지 확인합니다.

- **처음 실행 시** → 직접 입력
- **두 번째부터** → 저장된 정보가 자동으로 채워짐. 틀렸으면 수정 후 진행.

> ⚠️ 비밀번호가 변경된 경우 이 화면에서 새 비밀번호로 수정하면 자동 저장됩니다.

#### 업로드할 파일 폴더

분할 완료 후 자동으로 채워집니다.

이전 달 파일을 다시 업로드하려면 **선택** 버튼으로 해당 폴더를 직접 지정할 수 있습니다.

#### 업로드 범위 설정

| 상황 | 설정 방법 |
|---|---|
| 전체 파일을 한 번에 업로드 | **전체 파일 업로드** 체크 유지 |
| 일부 파일만 먼저 테스트 | 체크 해제 후 시작 번호 / 끝 번호 직접 입력 |

> 💡 처음 사용 시 **1번 파일만 먼저 테스트**해보고, 정상 업로드가 확인되면 나머지를 전체 업로드하는 것을 권장합니다.

#### 업로드 시작

**▶ 업로드 시작** 버튼을 클릭합니다.

크롬 브라우저가 자동으로 열리며 아래 순서로 진행됩니다.

```
[ 파일 분할 ]
✅ 분할 완료 → N개 파일

[ 업로드 ]
  크롬 드라이버 초기화 중...
✅ 크롬 드라이버 초기화 완료

  로그인 시도 중...
✅ 로그인 완료

  [1/N] 현금영수증_분할_1.xlsx 업로드 중...
✅ [1/N] 현금영수증_분할_1.xlsx 업로드 완료
  [2/N] 현금영수증_분할_2.xlsx 업로드 중...
✅ [2/N] 현금영수증_분할_2.xlsx 업로드 완료
  ...

🎉 완료!
```

> 업로드가 진행되는 동안 **크롬 창을 직접 조작하지 마세요.**

---

### Step 5. 완료 확인

아래 팝업이 뜨면 업로드가 정상적으로 끝난 것입니다.

```
┌─────────────────────────────┐
│           완료              │
│                             │
│  N개 파일을 모두             │
│  업로드했습니다!             │
│                             │
│  창을 닫아도 됩니다.         │
│                             │
│           [  확인  ]        │
└─────────────────────────────┘
```

**확인** 을 누르고 프로그램 창을 닫으면 완료입니다.

---

> ## 오류 발생 시

오류가 발생하면 업로드가 즉시 중단되고, 로그 창에 빨간 글씨로 원인이 표시됩니다.

| 오류 메시지 | 원인 | 해결 방법 |
|---|---|---|
| `DRM 보안이 걸려 있거나 손상된 파일` | 파일에 DRM 보안 적용됨 | 회사 PC에서 DRM 해제 후 재시도 |
| `엑셀 파일에 데이터가 없습니다` | 파일 형식 오류 또는 파일 손상 | `.xlsx` 파일인지 확인 후 재시도 |
| `크롬 드라이버 오류` | 크롬 브라우저 미설치 | 크롬 설치 후 재시도 |
| `로그인 오류` | 아이디 또는 비밀번호 오류 | 로그인 정보 확인 후 재시도 |
| `N번째 파일 오류로 중단됨` | 업로드 중 네트워크 오류 등 | 잠시 후 해당 번호부터 범위 지정하여 재시도 |

> 오류 해결이 어려운 경우 **010-5033-1343** 으로 문의 바랍니다.
